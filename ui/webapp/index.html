1.12

Design System

“Aurora” is the design language behind this concept: Apple Human Interface Guidelines measurements (colours, type scale, radii, motion, elevation) wrapped around Workrave’s timebar semantics. Tokens live in css/tokens.css; components in css/app.css.

System colours

The twelve Apple system colours in the default light and dark variants — the palette every control in this UI draws from.

Type scale

HIG typography — Large Title down to Caption 2 — rendered with the system font stack so San Francisco appears on Apple devices.

Shape

The apps.apple.com radius ladder, from 5 px keys to 24 px sheets, plus the capsule. Nested corners stay concentric.

Elevation

Apple’s measured shadow recipes: thumb, card, multi-layer lift and glass material with its inner stroke.

Controls

iOS-geometry controls: 51 × 31 switch, 32 px segmented capsule with sliding thumb, 44 px capsule buttons, 4 px sliders with 26 px thumbs. Try them — they all work.
